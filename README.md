# HotLoop-io

The legal and brand home for HotLoop. Two things live here, and both are the only copy that counts.

**The license.** [LICENSE.md](./LICENSE.md) is the HotLoop Community License. It governs **HotLoop IoT, HotLoop Edge, HotLoop Gateway and HotLoop Edge Relay**: source-available, free for individual use, and business use goes through [EmberNET](https://embernet.ai), where sign-up is free and business use of HotLoop is free. **HotLoop Flow** is a separate product under [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0), free for everyone, businesses included. The docs site mirrors this file word for word and its build fails if the mirror drifts, so when the license changes, it changes here first. The plain-language version is on the [org homepage](https://github.com/HotLoop-io) and at [docs.hotloop.io/licensing](https://docs.hotloop.io/licensing/), and the legal text wins every argument with either of them.

**The brand.** [brand/](./brand) holds the design tokens, the logo files, and the written standard for color, type and voice. `brand/tokens.css` is the one copy of the palette that decides anything. [hotloop.io](https://hotloop.io) and [docs.hotloop.io](https://docs.hotloop.io) each vendor a copy, and each one's build fetches this file and fails if its copy has drifted. So change a color here, then copy it over, or neither site deploys. Anything else carrying a copy keeps it in step by hand, so check it when you change one.

Everything else about HotLoop, the actual homepage included, lives at [github.com/HotLoop-io](https://github.com/HotLoop-io).
